# Bigger Ender Chest

Bigger Ender Chest is a lightweight Fabric mod for Minecraft that doubles vanilla Ender Chest storage capacity.

## Features

- Expands Ender Chest storage from 27 slots (3 rows) to 54 slots (6 rows).
- Full singleplayer and multiplayer compatibility.
- Dedicated server support (players do not need the mod client-side when installed on a server).
- Preserves existing contents stored in the original 27 slots.
- Uses standard vanilla container rendering (double chest 6-row GUI).
