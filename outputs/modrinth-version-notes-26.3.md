# Bigger Ender Chest 0.1.0 (Minecraft 26.3)

Updated release compiled for the latest Minecraft 26.3 release.

- Expands vanilla Ender Chest storage from 27 slots (3 rows) to 54 slots (6 rows).
- Full singleplayer and multiplayer compatibility.
- Uses standard double chest 6-row GUI.
- Compatible with Fabric Loader >=0.15.0 and Fabric API 0.161.0+26.3.

### Release Jar
- `biggerenderchest-26.3-0.1.0+mc26.3.jar` (Target Minecraft Version: `26.3`)
